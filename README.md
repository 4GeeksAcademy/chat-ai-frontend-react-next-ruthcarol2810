# chat-ai-frontend-react-next-ruthcarol2810
Proyecto Chat para una IA, frontend creado con Vercel, backend Github Codespaces Copilot

## COMO INICIAR EL PROYECTO FRONTEND EN DEV
### COMANDOS APLICADOS LUEGO DE SUBIR LOS ARCHIVOS 

#### Extraer cambios del repositorio
git pull origin main

#### Instalar las dependencias
Antes de arrancar cualquier servidor, necesitas instalar los paquetes que el proyecto requiere. Corre uno de los siguientes comandos según el archivo de bloqueo que veas en tu proyecto (package-lock.json, yarn.lock o pnpm-lock.yaml):
bash
- Si usa npm (verás un package-lock.json)
npm install

- Si usa yarn (verás un yarn.lock)
yarn install

- Si usa pnpm (verás un pnpm-lock.yaml)
pnpm install

#### Lanzar puertos e iniciar
- Con los comandos nativos del proyecto:bash
npm run dev
- o también:
npm start
